# 💰 FinWise Women – AI-Based Financial Literacy Platform for Women

**FinWise Women** is an AI-based financial literacy platform designed to make financial knowledge **simple, practical, and accessible for women**.

The platform provides educational resources and practical tools to help users understand **budgeting, saving, investments, loans, insurance, digital payments, and financial safety**.

## 🌐 Live Demo

🚀 **Live Website:**
[Click here](https://ai-based-financial-literacy-platfor-seven.vercel.app/)

## 📌 About the Project

Many people face difficulties understanding financial concepts because of complicated terminology, lack of awareness, and limited access to practical financial education.

**FinWise Women** addresses this problem by combining:

* 📚 Financial education
* 📊 Budget planning
* 🎯 Savings goals
* 🤖 AI-based financial assistance
* 🛡️ Financial safety awareness
* 📱 Digital finance education

The goal is to help users develop better financial knowledge and financial-management habits.

## ✨ Features

### 📚 Financial Learning

Learn financial concepts through simple and easy-to-understand content.

* Financial security

### 📱 Digital Finance

Learn about:

* UPI
* Online banking
* Digital transactions
* Secure online payments

### 🔐 User Account

Users can create an account and access their financial-learning journey.

## 🚀 How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/AI-Financial-Literacy-Women.git
```

### 2. Open the Project

```bash
cd AI-Financial-Literacy-Women
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Start the Backend

```bash
npm run dev
```

The backend will start using Node.js and Nodemon.

### 5. Open the Frontend

Open the frontend `index.html` in your browser or use the VS Code Live Server extension.

## 🔑 Environment Variables

If your backend uses MongoDB or AI APIs, create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
AI_API_KEY=your_api_key
```

⚠️ **Never upload your `.env` file or API keys to GitHub.**

Add this to `.gitignore`:

```text
node_modules/
.env
```
